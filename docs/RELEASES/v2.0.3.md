# VideoHarvester v2.0.3

**English** · [简体中文](#简体中文) · [Download](https://github.com/Owl-Lee/VideoHarvester/releases/tag/v2.0.3)

This release improves download recovery, completion feedback, and behavior when browser cookie databases are temporarily locked.

## Changes

- Retry public downloads without browser cookies when an open browser prevents cookie database access.
- Preserve output names across retries so existing `.part` files can resume.
- Clean matching partial files after success and provide a manual cleanup action.
- Avoid success notifications when every queued item failed.
- Remove matching input links when completed or skipped task records are cleared.
- Add the VideoHarvester icon to the executable and Windows interface.

## Packages

- **Full:** includes VideoHarvester, yt-dlp, FFmpeg / ffprobe, and Deno.
- **Lite:** includes the app and guide; required tools are prepared on first use.

## 简体中文

**[English](#videoharvester-v203)** · 简体中文 · [下载](https://github.com/Owl-Lee/VideoHarvester/releases/tag/v2.0.3)

此版本重点改善下载恢复、完成反馈，以及浏览器 Cookie 数据库被占用时的处理。

### 变更

- 浏览器占用 Cookie 数据库时，公开内容可自动改用无 Cookie 方式重试。
- 重试时保持输出文件名稳定，使已有 `.part` 文件可以续传。
- 成功后清理对应的残留分片，并提供手动清理入口。
- 队列全部失败时不再显示成功提示。
- 清理已完成或已跳过的任务记录时，同时移除对应输入链接。
- 为可执行文件和 Windows 界面加入 VideoHarvester 图标。

### 安装包

- **完整版：**包含 VideoHarvester、yt-dlp、FFmpeg / ffprobe 和 Deno。
- **轻量版：**包含应用与使用说明，首次使用时自动准备依赖工具。
